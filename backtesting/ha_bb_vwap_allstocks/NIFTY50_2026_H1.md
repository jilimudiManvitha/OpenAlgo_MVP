# Four strategies on Nifty 50 stocks: January-June 2026

The September 15 request replaces the stopped full-history experiment with
a separate six-month run. Selected versions: S092 buy 1m (6.5R), S109 buy 5m
(13R), S299 sell 1m (9R), S305 sell 5m (10R).

## Universe and coverage

The fixed basket comes from `stock_symbols_CSVs/ind_nifty50list.csv`.
Read-only source inspection found 49 of its 50 stocks for January 1 through
June 30, 2026, inclusive: 2,205,000 minute rows, 45,000 per stock, across
120 source dates. BAJAJ-AUTO is absent, including under alternate BAJAJ
spellings. Do not substitute another Bajaj company. The available-data run
must explicitly exclude and disclose this missing stock.

This is a frozen basket, not a reconstruction of daily index membership.
The [February 23 NSE Indices announcement](https://www.niftyindices.com/Press_Release/ind_prs23022026.pdf)
states that the March 2026 review made no Nifty 50 constituent changes;
this does not independently certify every row of the local snapshot.

Both modeled paths (OLHC/OHLC), original strategy factories, 600-bar
indicator warmup, Rs 100,000 per-stock entry cap, 5 bps slippage, existing
research fees and VectorBT reconciliation remain enabled. Pre-January bars
initialize indicators only; reported trades stay in the requested range.
All four versions test every included stock. No hindsight gainers/losers
filter is applied. Current instrument metadata and the other limitations
in [README.md](README.md) still apply.

## Run and monitor

From `D:/Personal/openalgo` in PowerShell:

```powershell
# Start once, only if no writer for this output is running.
& backtesting/.venv/Scripts/python.exe -u -m backtesting.ha_bb_vwap_allstocks.run_selected_four --config backtesting/ha_bb_vwap_allstocks/nifty50_2026_h1.json

# Resume after an interruption; first verify the old writer has stopped.
& backtesting/.venv/Scripts/python.exe -u -m backtesting.ha_bb_vwap_allstocks.run_selected_four --config backtesting/ha_bb_vwap_allstocks/nifty50_2026_h1.json --resume

# Optional dashboard: http://127.0.0.1:8779
& backtesting/.venv/Scripts/python.exe -m backtesting.ha_bb_vwap_allstocks serve --config backtesting/ha_bb_vwap_allstocks/nifty50_2026_h1.json --port 8779

# Read background progress.
Get-Content backtesting/ha_bb_vwap_allstocks/nifty50_2026_h1_output/run.log -Tail 12
```

Results are isolated in `nifty50_2026_h1_output/`. The wrapper builds
`comparison/index.html` and its findings/CSV exports after all 120 days
commit. `process.json`, `run.log` and `run.err.log` record background launch
and progress; confirm process liveness rather than relying on saved PID alone.
Daily transactions allow resume without repeating committed days.
The stopped full-history results are preserved separately.

No final strategy ranking exists until this run completes. The narrower
scope reduces replay work substantially, but runtime is not yet measured.
